# quantum-networks

This repository is part of a reading course on Quantum Networks under the supervision of Prof. Christian Schaffner at University of Amsterdam.

### Course components:
1. EdX course: Quantum Hardware and its Applications with Quantum Inspire
2. EdX course: Quantum Communication and the Quantum Network Explorer
3. Implementation of quantum cryptography protocols using SquidASM
4. Independent project: Implementation of Quantum Position Verification protocol


Disclaimer: SquidASM and NetSquid requires the account setup (currently not publically available) and therefore the scripts will not run as is. For reference, the outputs from local execution can be found in output.txt file of each protocol.
